Project 2

Описание:
Project 2 - проект представляет собой учебное ядро интернет-магазина, построенное на принципах объектно-ориентированного программирования. Обновлены все модули.

Функциональность:
- Базовый класс `Product` для товаров
- Классы-наследники `Smartphone` и `LawnGrass` для специфических товаров
- Класс `Category` для категорий товаров
- Загрузка данных из JSON файла
- Магические методы для строкового представления и сложения товаров
- Ограничения на сложение товаров разных типов
- Ограничения на добавление только продуктов в категории

Тестирование:
В проекте реализованы автоматические тесты с использованием pytest и фикстур. Добавлены тесты (loader.py и models.py).

1. Запуск тестов:
poetry run pytest
2. Проверка покрытия:
poetry run pytest --cov=src

Тестируемые модули: loader.py, models.py.
