Project 2

Описание:
Project 2 - проект представляет собой учебное ядро интернет-магазина, построенное на принципах объектно-ориентированного программирования. Обновлены все модули.

Функциональность:

## Новая функциональность

### Валидация создания продуктов
- Добавлена проверка количества товара при создании
- При попытке создать товар с количеством 0 выбрасывается исключение `ZeroQuantityError`

### Расчет средней цены
- Добавлен метод `middle_price()` для класса `Category`
- Метод возвращает среднюю цену товаров в категории
- Для пустых категорий возвращается 0

### Обработка исключений
- Реализовано пользовательское исключение `ZeroQuantityError`
- Добавлена обработка исключений при добавлении товаров в категории
- Реализованы блоки `try/except/finally` для обработки ошибок

### Тестирование
- Добавлены тесты для новой функциональности
- Обеспечено покрытие кода тестами более 75%

Тестирование:
В проекте реализованы автоматические тесты с использованием pytest и фикстур. Добавлены тесты (loader.py и models.py).

1. Запуск тестов:

2. Проверка покрытия:
poetry run pytest --cov=src
